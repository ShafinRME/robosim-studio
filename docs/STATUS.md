## Decisions (Day 08)
- ADR 005: **Dexie 4.4.7** (Apache-2.0, `apps/web`), **fflate 0.8.3** (MIT, core; 0.8.3 fixes GHSA-px8p ZIP64 loop),
  **fake-indexeddb 6.2.8** (Apache-2.0, dev). No runtime deps; audit 0. `.rsim` = zip of `manifest.json` +
  `project.json` with real-size limits while inflating; share link in the URL `#` fragment (never sent to a
  server), ≤ 8 000 chars; imported/shared projects get a new id.
- `apps/web/src/lib/project-db.ts`: database `robosim-studio`, tables `projects` (id, updatedAt index, summary +
  project) and `settings` (open tabs). `saveProject` sets `updatedAt` in the saved copy; `loadProject` always
  migrates + validates and checks the id matches its key; `listRecent` newest first (summaries only); session
  cleaned (valid ids, no duplicates, ≤ 12, active must be open). Errors → `StorageError` kind quota / unavailable /
  unknown (Dexie's wrapped errors checked). 12 tests with fake-indexeddb, incl. tampered records. 293 unit tests.
- Autosave (`apps/web/src/app/studio/open-projects.ts`): one store per open project; saved 1 s after the last edit;
  open tabs + active tab saved and restored after a reload ("Opening your projects…" meanwhile); bad saved
  projects skipped with a warning; storage problems reported once. Project ids are now random (`newId`).
  **Found while testing:** an IndexedDB write started while the page closes never finishes → on `pagehide`
  unsaved projects are also written synchronously to localStorage (`lib/unsaved-backup.ts`, ≤ 2 MB, validated
  on load, cleared after each successful database save). Undo history starts fresh after a reload.
- `.rsim` (`packages/core/src/archive.ts`): `writeArchive` (deterministic zip: manifest + project) /
  `readArchive` (≤ 10 MB, zip signature, only known entries, ≤ 16 entries, streaming inflate with real-size
  limits 5 MB/entry, 20 MB total, manifest format/version check, then `parseProject`); `archiveFileName`
  (safe name); `copyProject` gives imports a new id. 27 tests incl. round trip and a 30 MB zip bomb.
  Studio: File → Import project… / Export project (palette commands too). `APP_VERSION` moved to `core/src/app.ts`.
  325 unit tests, 62 e2e (6 new).
- Share links (`packages/core/src/share.ts`): deflate + own base64url; `/studio#share=…` (fragment, never sent to
  a server); ≤ 8 000-char token (bigger → "export a .rsim instead"); reading caps unpacked JSON at 1 MB (streaming
  inflate) and validates with `parseProject`. 20 tests incl. a bomb hidden in a short link. Studio: File → Copy
  share link (clipboard); opening a link (also pasted into an open studio) opens a copy (new id) and removes the
  link from the address bar.
- Recent projects window (`recent-projects-dialog.tsx`): File → Recent projects… / Alt+O / button on the empty
  workspace; lists saved projects newest first (lab, parts, changed time, "open"); Open (or switch to its tab);
  Delete needs a second click ("Delete for good?") and closes its tab. Pending edits are saved before listing.
  345 unit tests, 66 e2e (4 new).
