# RoboSim Studio

**A free, open-source robotics lab that runs in your browser.**
Design circuits, program Arduino, ESP32 and Raspberry Pi Pico boards, model sensors and actuators,
tune controllers, simulate power electronics, drive robots in 2D and 3D physics worlds, and learn
ROS 2 — from beginner to advanced, with no installation and no paid licences.

> 🚧 **Status:** early development (Phase 0 — Foundation). See [`docs/PLAN.md`](docs/PLAN.md) for the roadmap.

## Planned labs
| Lab | What you can do |
|---|---|
| Circuit Lab | Schematic & breadboard editor, DC / transient / AC analysis, multimeter, oscilloscope |
| Microcontroller Lab | Real Arduino (Uno, Nano, Mega) and Raspberry Pi Pico firmware, C++, MicroPython, blocks |
| ESP32 & IoT Lab | ESP32 / S3 / C3: GPIO, PWM, ADC, FreeRTOS, deep sleep, Wi-Fi, HTTP, MQTT, BLE |
| Sensors & Actuators | Realistic sensor noise/bias models, motors, drivers, steppers, displays |
| 2D Robotics Lab | Physics worlds, differential-drive and other robots, line followers, mazes |
| Control & Power Lab | Block diagrams, PID / LQR, Bode & root locus, buck/boost converters, solar MPPT |
| 3D Robotics Lab | Robot arms, mobile robots, drones, LiDAR and cameras, URDF import |
| ROS Lab | ROS 2 concepts in the browser, navigation & SLAM, bridge to real ROS 2 |
| Learning Platform | Lessons with live labs, auto-graded tasks, classrooms, English & Bangla |

## Successor to RoboSim
RoboSim Studio grows out of [RoboSim](https://robosim-bd.vercel.app/landing), a browser-based
robot-arm simulator (kinematics, IK, dynamics, URDF, 10 tutorials).
